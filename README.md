## 🎯 Project Overview
This project is a modern task management dashboard built using **HTML5, CSS3, and Vanilla JavaScript**. It focuses on providing a seamless user experience while demonstrating core programming concepts like data persistence and array manipulation.

### ✨ Key Features
* **Persistent Storage:** Data is saved in the browser using `localStorage`, so tasks remain after a page refresh.
* **Dynamic Filtering:** Users can toggle between "All," "Pending," and "Completed" tasks using JavaScript `.filter()`.
* **Priority System:** Tasks are color-coded (High, Medium, Low) to help students focus on what matters most.
* **Responsive Design:** Fully optimized for both desktop and mobile devices.

## 🛠️ Technical Implementation
1. **HTML5:** Used semantic tags for better SEO and accessibility.
2. **CSS3:** Implemented Flexbox and CSS Grid for a clean, modern dashboard layout.
3. **JavaScript (ES6+):**
   * **Higher-Order Functions:** Used `.map()` for status toggling and `.filter()` for task deletion and navigation.
   * **Local Storage API:** Implemented for data persistence.
   * **DOM API:** Real-time UI updates without reloading the page.
